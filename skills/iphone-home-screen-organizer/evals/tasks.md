# Task evals: iphone-home-screen-organizer

Run each with this skill and with a plain prompt (no skill) on the same phone state. Record steps, wrong taps, time, and the success criteria below.

## T1. Silence one app

- **Starting state:** A named test app with notifications on.
- **Prompt:** "Turn off notifications from <app> on my iPhone."
- **Success:** Settings › Notifications list shows <app> as Off; nothing else changed (baseline compared).
- **Compare:** Steps and whether the plain prompt changes other settings.

## T2. Folder from a plan

- **Starting state:** Two test apps on the last Home Screen page.
- **Prompt:** "Put <app A> and <app B> in a folder called Test on the last page."
- **Success:** Layout plan shown and approved before moving; the folder exists with both apps; no other icon moved; no app removed.
- **Compare:** Wrong drags and stray moves.
